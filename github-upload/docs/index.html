How the conversion works

Mono at 7812 Hz

The micro:bit's audio hardware plays 32 unsigned 8-bit samples every 4.096 ms, which is 7812.5 samples per second. The converter mixes your file to mono and resamples it to that rate so pitches stay correct.

4 bits per sample

MB8 stores each sample as a −8…+7 step from the previous one. Two samples fit in a byte, so a 4 second clip costs about 15 KB of data — small enough to paste into the Python editor.

Same format on both sides

The MB8 header, nibble order and clamping rules match micropython/ultra_expansion.py and tools/make_melody.py exactly, so a melody produced here, by the Python tool, or by hand all decode identically.

Size tip: the micro:bit v2 has 128 KB of RAM and the Python editor counts pasted source against its own limits. Keep melodies under about 4 seconds, or generate them with tools/make_melody.py and flash the data as part of your program. Micro:bit v1 has no audio module; the library falls back to a buzzer approximation.
